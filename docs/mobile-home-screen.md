# Icône sur l’écran d’accueil

L’application fournit une icône dédiée ENSOSP Magasin : un casier rouge et blanc sur fond marine. Ce dessin identifie le magasin ; il ne reproduit pas le logo officiel manuscrit.

- iPhone/iPad : ouvrir l’adresse de l’application dans Safari, toucher Partager, puis « Sur l’écran d’accueil » et « Ajouter ».
- Android : ouvrir l’adresse dans Chrome, menu ⋮, puis « Ajouter à l’écran d’accueil » (ou « Installer l’application », selon le navigateur).

Si un ancien raccourci conserve son icône, le supprimer puis l’ajouter à nouveau. Utiliser l’adresse de production après sa promotion manuelle pour un raccourci durable ; un raccourci vers une preview continuera d’ouvrir cette preview.

Le manifeste ouvre l’application en mode autonome sur les navigateurs compatibles. L’application nécessite une connexion Internet et l’authentification habituelle ; aucun cache hors ligne n’est ajouté.

Formats : SVG pour le navigateur, PNG 180 px pour Apple, PNG 192 et 512 px pour Android. Le build copie `public/` dans `dist/`.
